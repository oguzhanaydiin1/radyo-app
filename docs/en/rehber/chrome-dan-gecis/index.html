Moving bookmarks and passwords from Chrome

The most annoying part of switching browsers is setting up bookmarks and passwords again. It actually takes about five minutes.

1. Export your bookmarks from Chrome

  1. In Chrome, type chrome://bookmarks in the address bar (or press Ctrl+Shift+O).
  2. Click the three dots (⋮) at the top right and choose Export bookmarks.
  3. An .html file is saved; note where you saved it.

2. Export your passwords from Chrome

  1. Type chrome://password-manager/settings in the address bar.
  2. Click Export passwords. You’ll be asked to confirm with your Windows or phone lock.
  3. A .csv file is saved.

Careful: the .csv file contains your passwords unencrypted, in plain text. Delete it right after importing and empty the Recycle Bin.

3. Import into Pusula Browser

  1. In Pusula, open Settings → Passwords → Import from Chrome / Edge / Firefox. (Or from the command box: Ctrl+K, type “import”.)
  2. Choose Bookmarks (.html file) and pick the file from Chrome.
  3. Choose Passwords (.csv file) and pick the password file.

Bookmarks and passwords you already have aren’t added twice. In Pusula, passwords are kept in your device’s secure storage.

From Edge or Firefox

You can get the same two files from these browsers: in Edge, edge://favorites (⋮ → Export favorites) and edge://wallet/passwords; in Firefox, Bookmarks → Manage all bookmarks → Import and Backup, and about:logins (⋯ → Export logins).

Last step: make it your default browser

On Windows, choose Pusula Browser in Settings → Apps → Default apps; on Android, in Settings → Apps → Default apps → Browser app. Links in emails and messages will then open in Pusula.

If you sign in with the same OA Labs account on your computer and phone, your bookmarks reach the other device by themselves, so you only need to import once.

Pusula Browser is free, for Windows and Android.
