# OA Radyo — Android (test)

Web oynatıcısı (`docs/dinle`) Capacitor ile bir Android uygulamasına sarılır.
GitHub Actions'taki **Android test APK** iş akışı derler ve `android-test` sürüm
sayfasına `OA-Radyo-test.apk` olarak koyar. Android projesi her derlemede
yeniden üretilir; burada yalnızca yapılandırma ve simgeler tutulur.
